# Reverse String

- **Problem Name:** Reverse String
- **Difficulty:** Easy
- **LeetCode Link:** [leetcode.com/problems/reverse-string](https://leetcode.com/problems/reverse-string/)
- **Approach:** Use two pointers at the beginning and end of the character array, swapping inward until they meet.
- **Time Complexity:** $O(n)$
- **Space Complexity:** $O(1)$
- **Notes:** The input array is modified in place. The standalone `main` tests two strings.

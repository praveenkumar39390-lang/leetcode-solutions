# Two Sum

- **Problem Name:** Two Sum
- **Difficulty:** Easy
- **LeetCode Link:** [leetcode.com/problems/two-sum](https://leetcode.com/problems/two-sum/)
- **Approach:** Check each distinct pair and return the indices as soon as their values sum to the target. The returned array is heap-allocated for compatibility with the LeetCode C signature; the caller owns it.
- **Time Complexity:** $O(n^2)$
- **Space Complexity:** $O(1)$ auxiliary space, excluding the two-element result.
- **Notes:** The standalone `main` checks two input cases. Compile this file separately from the other solutions.

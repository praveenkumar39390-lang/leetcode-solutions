# Move Zeroes

- **Problem Name:** Move Zeroes
- **Difficulty:** Easy
- **LeetCode Link:** [leetcode.com/problems/move-zeroes](https://leetcode.com/problems/move-zeroes/)
- **Approach:** Copy nonzero values forward in their original order, then fill the unoccupied suffix with zeroes.
- **Time Complexity:** $O(n)$
- **Space Complexity:** $O(1)$
- **Notes:** Modifies the array in place and preserves the relative order of nonzero values. Includes two test cases.

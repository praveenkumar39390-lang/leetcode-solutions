## Project Description
A collection of independently compilable C solutions to selected LeetCode problems. Each program includes its solution, explanatory comments, and at least two assertions that exercise the implementation.

Compile and run an individual solution with GCC:

```sh
gcc -std=c11 -Wall -Wextra -Werror arrays-strings/01-two-sum.c -o two-sum
./two-sum
```

Repeat with the desired `.c` path and an output name for another problem.
